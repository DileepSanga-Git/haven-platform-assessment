# B0 — The `count` trap

What does `terraform plan` show when a middle landlord account is removed from the list? Why is

That is dangerous beacuse landlord-specific media storage. An incorrect resource can cause unnecessary infrastructure changes and create risks around resource ownership and cost.

So I replaced count with for_each, using each landlord account ID as the resource key. This provides stable resource addresses independent of the account's postion in the input data.

I have reproduced the actual origibal issue using the terraform state and terraform plan --refresh=false. Then applied the for_each configuration and compared the resulting plan. I didn't applied terraform plan, because here we are not creating the actual infrastructure till now.
